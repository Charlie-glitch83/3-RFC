# M_rec and the Return of Memory

Many source files show a recurrence grammar:

```text
CIF_s -> QV_s -> RFL_s -> M_rec -> CIF_{s+1}
```

At first glance, `M_rec` can look like a fourth component. It is not.

The triad remains:

```text
CIF / QV / RFL
```

`M_rec` is the return path.

It is the inheritance membrane between RFL memory and the next CIF condition.

## Why return is necessary

If RFL only remains but never returns, emergence stops. The triad would produce isolated outputs.

If RFL returns by becoming the source-parent directly, recurrence becomes confused. Memory would pretend to be origin.

`M_rec` solves both problems:

```text
RFL memory is carried forward.
RFL memory does not become the parent.
```

This is why `M_rec` is so important.

It lets the triad recurse without collapsing phase distinction.

## The difference between source and condition

A source is not the same as a condition.

RFL can condition the next CIF. But RFL is not identical to CIF.

The next CIF is not pure blank possibility. It is possibility shaped by inherited memory. But the source side remains a source side. It is not merely the previous output renamed.

This gives the recurrence:

```text
qualified memory -> inherited condition -> new admitted possibility
```

Then QV acts again.

## Collapse-rebirth as memory return

The collapse-rebirth sources show this clearly.

Collapse is not mere destruction. Rebirth is not arbitrary restart.

The pattern is:

```text
collapse -> inherited packet -> selection/compression -> stabilized output -> next-stage rebirth
```

This is the triad loop in another body.

`RFL` preserves what can survive. `M_rec` carries it across transition. The next `CIF` is conditioned by that memory.

So rebirth is not magic. It is memory-qualified recurrence.

## Failure as return

Failure can also become memory.

A failed route is not RFL merely because it failed. But if it records where the crossing broke, what source was missing, what scalar flattened the relation, or what witness was absent, then the failure becomes qualified memory.

Then it can condition the next CIF.

This gives a research form of the triad:

```text
possible route -> tested crossing -> failure memory -> better next possibility
```

This is one of the deepest expressions of the triad. Even error can become RFL if it stabilizes as useful memory.

## Memory-return errors

The return loop is misunderstood when one says:

```text
RFL becomes CIF directly
```

or:

```text
memory alone generates the next act
```

The correct version is:

```text
RFL memory conditions the next CIF, then QV acts again.
```

Past memory is not present action.

A prior stabilized state can shape the next field, but it cannot replace the new crossing.

## One-line definition

> M_rec is the inheritance membrane that lets RFL memory condition the next CIF without becoming the source-parent.

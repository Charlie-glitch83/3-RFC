# Scalar Collapse: The Main Failure Mode of the Triad

The most repeated failure pattern across the sources is scalar collapse.

Scalar collapse means reducing the triadic relation to one number too early.

The triad is relational:

```text
source -> crossing -> memory -> return
```

A scalar is only a projection of that relation. It can be useful after the relation is preserved. It becomes dangerous when it replaces the relation.

## Why scalar collapse breaks the triad

A scalar can preserve magnitude while destroying provenance.

It can say:

```text
there are N survivors
```

But it may not say:

```text
what source admitted them
what crossing exposed them
what witness confirmed the crossing
what memory they carry
how they return into the next field
```

The triad cares about all of that.

## BBN scalar collapse

The W2 BBN closeout is the clearest physical-style example.

The old lane used a collapsed triad scalar. It erased channel structure and left the Li7 branch overproduced.

The revised lane restored triadic channel weights. The internal ledger preserves values like:

```text

TriadicLi7OverObserved   = 0.999643
QVOnlyLi7OverObserved    = 0.983826
CIFOnlyLi7OverObserved   = 3.64564
RFLOnlyLi7OverObserved   = 2.48007
```

The lesson is not merely that a number improved.

The lesson is:

```text
Li7 behavior was channel-dependent, so scalarizing the triad destroyed the mechanism.
```

## Arithmetic scalar collapse

The twin-prime sources give the arithmetic version.

Wrong:

```text
survivor count
deletion count
remaining count
```

Correct:

```text
CIF = admitted survivor support
QV  = legal active incidence/exposure
RFL = obstruction memory / recurrence / echo ledger
```

The public proof refuses marginal q/M recombination. A deletion counts only when the coupled tuple exists:

```text
(k, sigma, q, M)
6k + sigma = qM
M >= 2
```

This is scalar-collapse resistance in pure form.

## The shadow rule

The best phrase is:

```text
A scalar is a shadow cast by the triad.
It is not the triad.
```

A shadow can be measured. But it cannot replace the object casting it.

## When scalarization is allowed

Scalarization is not forbidden. It is allowed after relation has been preserved.

A scalar can summarize:

```text
closure score
abundance ratio
kernel value
survivor count
error metric
correlation
```

But it must remain downstream of the triad.

The scalar must be able to point back to source, crossing, memory, and return.

## The scalar test

Before trusting any scalar, ask:

```text
What CIF did it flatten?
What QV crossing did it flatten?
What RFL memory did it flatten?
What return/handoff did it flatten?
What witness did it preserve or lose?
```

If those questions cannot be answered, the scalar is not yet lawful.

## One-line rule

> A scalar can report a triadic event, but it cannot replace the triadic event.

# CIF: Admitted Source-Possibility

CIF is often first understood as possibility. That is true, but incomplete.

The more exact definition is:

```text
CIF = admitted source-possibility
```

CIF is possibility with source identity. It is the open field of what can become, but not random anythingness. CIF is infinite in the sense that it is not yet committed to one stabilized form, but it is not meaningless. It contains possible form, possible relation, possible branch, possible phase, possible structure.

The early sources speak of CIF as the global reservoir of infinite possibilities. That seed remains correct. The later sources sharpen it into modal source content, admitted source support, domain-specific possibility field, and the input side of the kernel.

## CIF as openness before commitment

CIF is what has not yet crossed into a stabilized result. It is the pre-actual side of emergence. It is where the field is still richer than the outcome.

CIF is not yet RFL. It has not stabilized.

CIF is not yet QV. It has not crossed.

CIF is not absence. It is pregnant openness.

A useful phrase is:

```text
CIF is uncommitted structure.
```

That phrase preserves both sides: it is open, but not empty.

## CIF as admission

The sources increasingly reveal that not all possibility counts as CIF. A possibility must be admitted into a lawful field of becoming.

In cosmology, CIF is not every imaginable universe. It is the modal possibility available to the triadic action.

In a module chain, CIF is not arbitrary data. It is the inherited source condition opened by `Phi_i`.

In BBN and nucleosynthesis, CIF is not all elements in fantasy. It is the layer-specific abundance channel space opened from the inherited state.

In arithmetic, CIF is not every integer. It is admitted survivor support after the old gate has formed the field on which active QV can operate.

So CIF asks:

```text
What has entered the field of lawful becoming?
What is open enough to become, but identified enough to be acted on?
```

```text
K_f(t)=sum_j delta^{-j} f_j(t) exp(-alpha j t)
```

`f_j(t)` corresponds to CIF modal content.

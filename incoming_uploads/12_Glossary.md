# Glossary of Triad and Kernel Terms

## Admitted possibility
Possibility that has source identity and can enter a lawful emergence process. A sharper name for CIF.

## CIF
Cosmic Infinite Field. The source-potential role of the triad. In mature language: admitted source-possibility.

## Collapse
One possible face of QV. Collapse should not be treated as mere destruction; it is a crossing from open possibility into more definite actuality.

## Crossing
The transition from possible to actual. The most general practical word for QV.

## Delta weighting
The `delta^{-j}` component of the recursive kernel. Interpreted as recursive depth weighting or compression/scaling.

## Damping
The `exp(-alpha j t)` component of the recursive kernel. Interpreted as QV damping/closure envelope.

## First Action
The primitive triadic action:

```text
QV(CIF) -> RFL
```

All later kernel forms are downstream of this action.

## Inheritable memory
Memory stable enough to condition later emergence. A sharper name for RFL.

## Kernel
The repeatable form of First Action. The kernel preserves the triad across recursive depth and domain-specific modal basis.

## K_f(t)
The recursive mathematical kernel:

```text
K_f(t)=sum_j delta^{-j} f_j(t) exp(-alpha j t)
```

## K_T
Weighted triad kernel:

```text
K_T=(w_QV QV,w_CIF CIF,w_RFL RFL)
```

## M_rec
Memory-return path or inheritance membrane. It carries RFL memory into the next CIF condition without making RFL the source-parent.

## Modal basis
The domain-specific content `f_j(t)` supplied by CIF. The modal basis lets the same kernel manifest in different domains.

## Phi
In module notation, the opening/source operator. It opens CIF from the inherited handoff.

## Psi
In module notation, the QV operator. It selects, exposes, compresses, or filters the CIF state.

## Omega
In module notation, the RFL operator. It stabilizes or locks output into memory-bearing form.

## Gamma
In module notation, the state-forming operator that combines CIF, QV, RFL, kernel closure, and handoff into the module state.

## QV
Quantum Vacuum. The crossing/selection/compression/actualization role. In mature language: witnessed/exposed lawful crossing.

## RFL
Recursive Fractal Lattice. The stabilized memory/output role. In mature language: inheritable qualified memory.

## Scalar collapse
The failure mode where source-crossing-memory relation is collapsed into a single number too early.

## Source identity
The property that distinguishes CIF from random possibility. CIF has source status.

## Triad
The irreducible emergence structure:

```text
CIF -> QV -> RFL
```

or:

```text
admitted source-possibility -> witnessed lawful crossing -> inheritable qualified memory
```

## Witness
The coupling evidence that a crossing actually connects source, operation, and result. In arithmetic, this appears as a proper legal tuple.

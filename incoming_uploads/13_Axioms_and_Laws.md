# Axioms and Laws of the Triad

This chapter states the triad as a set of laws. These are not meant to replace the source files; they are distilled from the repeated patterns across them.

## Law 1: Irreducibility

The triad has three roles because emergence requires three irreducible functions:

```text
CIF = what can enter becoming
QV  = what makes one path actual
RFL = what persists as memory
```

Remove CIF and QV has nothing to act on.

Remove QV and CIF never crosses.

Remove RFL and the crossing leaves no inherited structure.

The triad is minimal because no pair can do all three jobs.

## Law 2: Ordered emergence

The triad is ordered:

```text
CIF -> QV -> RFL
```

The components are one event seen in three phases, but they are not interchangeable.

CIF is before commitment.

QV is during commitment.

RFL is after commitment.

Order is not a presentation choice; it is part of the mechanism.

## Law 3: First Action

The primitive action is:

```text
QV(CIF) -> RFL
```

This is stronger than saying `QV + CIF -> RFL`. It says QV acts on CIF.

Possibility does not merely sit beside selection. Possibility is exposed to selection.

## Law 4: Source identity

CIF must be source-bearing.

A possibility does not qualify as CIF merely because it is imaginable. It must belong to an admitted field of lawful becoming.

This law prevents CIF from becoming random anythingness.

## Law 5: Witnessed crossing

QV must be witnessed.

A crossing does not qualify as QV if it is detached from the source it acts on and the result it produces.

This law appears most sharply in the arithmetic legal tuple rule, but it is general:

```text
no source-less action
no witness-less crossing
no detached deletion
```

## Law 6: Qualified memory

RFL must be qualified memory.

A trace does not qualify as RFL merely because it remains. It must stabilize enough to be inherited.

This law separates raw residue from memory.

## Law 7: Memory return without source impersonation

RFL returns through memory, but RFL is not the source-parent.

The corrected recurrence is:

```text
CIF_s -> QV_s -> RFL_s -> M_rec -> CIF_{s+1}
```

Not:

```text
RFL_s = CIF_{s+1}
```

This law prevents memory from pretending to be origin.

## Law 8: Kernel after triad

The kernel is downstream of the triad.

The order is:

```text
triad -> First Action -> kernel -> modal basis -> domain manifestation
```

If the kernel is placed before the triad, it becomes an arbitrary formula. If it follows First Action, it becomes recurrence.

## Law 9: Modal-basis discipline

A domain may manifest the triad through a domain-specific modal basis, but the modal basis must not be a free fitting handle.

In the kernel:

```text
f_j(t) = CIF modal content
```

So `f_j(t)` must be source-derived, declared, or otherwise lawful.

## Law 10: Scalar shadow law

A scalar can be produced by the triad, but a scalar cannot replace the triad.

A scalar is a shadow. The triad is the relation casting it.

Any scalar must be reopened into:

```text
source
crossing
witness
memory
return
```

## Law 11: Gate separation

Past memory is not present action.

Old completion is not active exposure.

Diagnostic trace is not final memory.

Internal stabilization is not external validation.

The general triad lesson is:

```text
do not confuse gates
```

## Law 12: No hidden channel

Do not invent a new free channel when existing triadic routing can account for the event.

This law is why the triad can be infinitely complex without becoming complicated.

Complexity enters through recursion and modal basis. Complication enters through unlicensed channels.

## Law 13: Failure can become memory

A failure is not automatically RFL, but it can become RFL if it stabilizes as useful obstruction memory.

The triadic form is:

```text
possible route -> tested crossing -> retained obstruction -> next source condition
```

This law makes learning itself triadic.

## Law 14: Provenance preservation

Every lawful manifestation must preserve provenance:

```text
from what source?
through what crossing?
with what witness?
into what memory?
by what return?
```

This may be the deepest practical law of the triad.

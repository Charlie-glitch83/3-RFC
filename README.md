## 4. Absolute operating locks

These rules are binding.

### 4.1 Source and terminology

- CIF means **Cosmic Infinite Field**.
- QV means **Quantum Vacuum**.
- RFL means **Recursive Fractal Lattice**.
- The First Action precedes the Big Implosion.
- The recursive kernel follows the triad and First Action.
- Exact source bytes are admitted by hash. A summary or remembered formula is not a scientific parent.
- Frozen source files are immutable. Revisions create new versioned objects.

### 4.2 No tuning

During universe generation, do not use public observations, best-fit parameters, remembered target values, target-trained surrogates, calibrated public simulations, or residuals to choose laws, coefficients, bases, branches, seeds, tolerances, or stopping rules.

A correction is lawful only when compelled by the triad, the exact parent, mathematics, dimensions, conservation, causality, covariance, branch completeness, numerical convergence, or a predeclared internal falsifier.

### 4.3 Failures are not inherited outcomes

Preserve evidence of prior failures, but do not preserve their failed mechanisms or outputs as parents.

Old failures may become:

- regression tests;
- negative controls;
- falsifiers;
- provenance warnings;
- representation checks.

They may not become the desired answer, a branch selector, a fitted correction, or a ceiling on a newly justified claim.

### 4.4 Evidence states cannot be skipped

The state ladder is:

```text
DESIGN
FORMALIZED
IMPLEMENTED
VERIFIED
PHYSICALLY_EXECUTED
ENSEMBLE_VERIFIED
INDEPENDENTLY_REPRODUCED
FROZEN
BLIND_VALIDATED

```

`BLOCKED`, `FAIL_REQUIRES_ANALYSIS`, and `FALSIFIED_AT_SCOPE` are explicit terminal or pause states.

No prose, document count, aggregate score, or old PASS label upgrades an object.

### 4.5 Componentwise gates

Mandatory gates pass individually. An average cannot hide a failed component.

The target is a clean pass or 1.0000 where a normalized diagnostic is scientifically meaningful. A diagnostic below 0.95 triggers `FAIL_REQUIRES_ANALYSIS`: inspect triadic representation, source admission, witness construction, branch coverage, conservation, dimensions, and numerical convergence. Do not lower the threshold or tune toward the answer.

### 4.6 N-body activation

Every domain declares one of three modes:

- `DORMANT`: carrier retained, exactly zero physical backreaction;
- `RELATIONAL_GRAMMAR_ACTIVE`: identity, relation, witness, route, event, branch, conservation, memory, or reopening are active without direct body mechanics;
- `DIRECT_MANY_BODY_ACTIVE`: physical constituents, clocks, geometry/phase space, interaction law, scales, constraints, and activation witnesses exist.

Do not activate direct many-body dynamics before the universe generates its physical prerequisites.

### 4.7 GitHub verification

A GitHub write is not complete until the model verifies:

- the exact repository and branch;
- the resulting commit SHA;
- the changed-file list;
- the fetched file content or branch comparison;
- CI/validation status when available.

If a write action returns no new SHA or no diff, stop immediately and switch methods. Never spend another long interval assuming an unverified write landed.

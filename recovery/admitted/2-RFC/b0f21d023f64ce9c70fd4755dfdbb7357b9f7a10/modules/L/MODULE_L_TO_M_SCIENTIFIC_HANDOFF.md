# Module L → Module M Scientific Handoff

## Purpose

This file seals the physical boundary between the baryonic, stellar, compact-object, feedback, and ejecta histories generated by Module L and the isotope-resolved stellar/explosive nucleosynthesis, chemical transport, dust, and composition-return universe owned by Module M.

It defines only:

- what Module L must export before Module M begins;
- which Module L events and trajectories are admissible for nuclear processing;
- which upstream nuclear, particle, thermal, and nonlinear states Module M may reopen without mutation;
- what Module M must derive rather than import;
- how isotope and energy ledgers remain connected to generated stellar and compact-object events;
- how chemical carriers move through the generated nonlinear universe;
- how composition-dependent physics returns to Modules K and L;
- how the K–L–M loop reaches a lawful closure state before Module N.

It does not adopt the former run system, run numbering, source-register bureaucracy, lifecycle machinery, gate taxonomy, proof-obligation ledger, certificate architecture, repository schema, or evidence paperwork.

# 2. Coupled order

The first-pass order is:

```text
K^(0) -> L^(0) -> M^(0)
```

The continuing physical loop is:

```text
K^(n) -> L^(n) -> M^(n) -> K^(n+1)
```

Module M returns composition, dust, cooling, opacity, radioactive power, mass return, and stress-energy changes. Those returns can alter:

- gas phases and cloud collapse;
- stellar structure and lifetimes;
- winds, feedback, and remnant formation;
- nonlinear baryonic structure;
- metric and lensing fields.

Only the affected forward physical interval is replayed. Modules A–J remain frozen.

The loop closes only as a fixed point, bounded cycle, slowly evolving attractor, classified branch family, or explicit nonconvergence.

# RFC Primordial Source Theorem — Derivation Plan

## Purpose

J-200 cannot lawfully manufacture a primordial covariance. The next scientific object is a theorem that derives the physical perturbation state from the existing CIF/QV/RFL lineage while preserving the repaired HI branch family and the generation firewall.

## Exact starting point

- Frozen parent: `modules/HI/frozen/H_HI_to_J_v2.json`.
- Genesis law: the Big Implosion is a deterministic strictly convex branch map with one manifested image per admitted fixed branch.
- P29 supplies the universal recursive kernel and normalized recursive-depth weights.
- P30 explicitly leaves the physical primordial spectrum, transfer functions and matter power spectrum pending.
- HI supplies a branch-indexed constraint-preserving tangent transfer operator, but no realized primordial covariance, phase seed or finite-volume field.

## Theorem target

For every exact repaired HI branch, derive a typed primordial state object

\[
\mathfrak P_b=(\mathcal V_b,\mu_b,\Sigma_b,\mathcal M_b,\Pi_b,\mathcal R_b),
\]

where `V_b` is the physical perturbation quotient, `mu_b` is a source-owned state law or complete lawful state-family measure, `Sigma_b` is finite Hermitian PSD covariance, `M_b` is the exact mode/projector structure, `Pi_b` is phase/seed provenance, and `R_b` is restart/ancestry memory. No component may be imported from observed cosmology or manufactured solver defaults.

## Required derivation chain

1. **Matching surface.** Identify the exact physical surface on the repaired lineage at which the primordial perturbation state is defined. It must be inherited from the genesis/background event order, not chosen for observational convenience.
2. **Physical perturbation space.** Specialize the HI/HU quotient `V_b=ker(C_b)/im(Gauge_b)` into a complete physical perturbation state space with a source-owned positive pairing or equivalent structure sufficient to define adjoints, projectors and covariance.
3. **QV state law.** Derive from the triad a state-selection/normalization principle. Deterministic branch admissibility is not enough. The result must state whether QV produces a probability measure, a quantum state/density operator, a deterministic complete ensemble, or another mathematically precise normalized state law.
4. **Kernel inheritance.** Prove exactly how P29 recursive weights act on the physical perturbation space. The proof must supply the recursion-to-mode/projector map; the weights may not simply be renamed as mode probabilities.
5. **Covariance theorem.** Derive `Sigma_b` from the state law and prove Hermiticity, PSD, finite normalization/dimensions, gauge compatibility and branchwise ancestry. If degeneracy prevents a unique basis, use spectral projectors or preserve the full degenerate family rather than tie-break.
6. **Transfer compatibility.** Prove `Sigma_b(t2)=U_HU[b;t2,t1] Sigma_b(t1) U_HU[b;t2,t1]^T` (or the appropriate adjoint form for the derived pairing) without retuning `U_HU`.
7. **Phase/seed theorem.** Derive phase statistics/provenance from the same state law. A hash may make a realization reproducible only after the physical distribution is derived; it cannot determine the distribution.
8. **Relational realization map.** Derive a finite-volume representation from the exact relational geometry. If the correct representation is graph-spectral rather than periodic Fourier, J must use that representation and the generic Fourier engine remains implementation-only.
9. **Promotion theorem.** State the exact conditions under which one realized field is promoted to `P_J_to_K` while retaining covariance, branch identity, seed provenance, uncertainty and restart memory.

- A periodic Fourier box chosen only because the solver expects one must fail.
- Gaussian, scale-invariant and independent-phase assumptions without source derivation must fail.
- Any branch/seed chosen because it improves agreement with CMB/LSS or matter-power data must fail the generation firewall.
